## Proyecto destacado: FaroLive

[![FaroLive](assets/farolive-banner.webp)](https://panel.farolive.xyz)

**FaroLive** es un bot multiservidor de Discord con panel web para detectar transmisiones, publicar anuncios y ofrecer perfiles públicos a creadores y al equipo de la plataforma.

- Twitch, YouTube y Kick con detección automática.
- TikTok mediante flujos guiados en Discord.
- Administración por roles y comunidades.
- Mensajes, menciones, filtros y vistas previas.
- Directorio y perfiles públicos compartibles.
- Moderación, métricas y auditoría global.
