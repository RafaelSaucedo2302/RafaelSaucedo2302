## Proyecto propio: FaroLive

[![FaroLive: plataforma para comunidades y creadores](assets/farolive-banner.webp)](https://github.com/RafaelSaucedo2302/FaroLive-Showcase)

Creé **FaroLive**, un bot multiservidor de Discord con panel web para centralizar anuncios de transmisiones, perfiles públicos y administración de comunidades.

- Detección automática de directos de **Twitch, YouTube y Kick**, con flujos guiados para **TikTok**.
- Panel con autenticación **OAuth2**, permisos por roles y administración por comunidad.
- Perfiles públicos de creadores, anuncios configurables, moderación y auditoría de acciones.
- Persistencia en SQLite, validación de datos y documentación de uso para administradores y comunidades.

**Tecnologías:** TypeScript, Node.js, Express, EJS, discord.js, SQLite e integración de APIs.
